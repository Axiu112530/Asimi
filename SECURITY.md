# Asimi security reporting

Report suspected vulnerabilities privately to the project maintainer through the maintainer's available private contact channel. Include the affected version, the safety boundary, and a reproduction using an isolated project or the dedicated test host. Include redacted logs where useful.

Use the explicit per-action approval flow when testing behavior. [Release security review](docs/release/SECURITY-REVIEW.md) · [Privacy notice](PRIVACY.md) · [Historical 0.2 security review](docs/0.2/SECURITY-REVIEW.md)
