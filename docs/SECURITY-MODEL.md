# DeskPilot AI MVP 0.1 安全模型

模型可以解释、分析和建议。副作用由独立审批触发。审批绑定后台保存的提案、目标和完整参数哈希，有效期结束、停止或目标变更后失效。执行意图和单次消费在同一 SQLite 事务记录。持久化失败不会报告成功。未知结果保持待人工核查。

| 能力 | 操作范围和保证 |
| --- | --- |
| Workspace | 由原生目录选择器注册本地固定盘目录。相对路径不得含绝对路径、遍历、保留名称或备用流。逐级核验并固定目录句柄。拒绝重解析点、链接和硬链接文件。限制深度、目录项、字节、匹配数并排除依赖、构建输出和常见秘密文件。 |
| 创建 | 单文件，验证父目录及工作区身份。写入并刷新临时文件后以相对句柄无覆盖提交。独立重读身份和 SHA-256。 |
| 替换 | 单文件，绑定原内容及文件身份。Windows 本地 NTFS 事务写入先取得目标写入和重命名隔离，再复核内容、写入恢复副本并提交。事务 API 不可用或目标冲突时拒绝写入。提交或核验不确定时保留恢复证据。Microsoft 将 TxF 标为不建议用于新应用，今后的 Windows 兼容性需要验证。参考 [TxF 隔离和锁](https://learn.microsoft.com/en-us/windows/win32/fileio/txf-basic-concepts) 与 [CreateFileTransactedW](https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-createfiletransactedw)。 |
| 命令 | 固定 ID 和参数模板。解析绝对可执行文件，核验文件哈希、工作目录身份，拒绝网络路径和重解析路径。以普通用户挂起创建进程，加入 Windows Job Object 后启动，限制 32 个活动进程、2 GiB、50% CPU、最长 120 秒和 128 KiB 输出。取消终止该 Job。 |
| 项目运行 | 项目测试和部分 Git 配置可能执行用户代码，因此需要明确勾选可能使用网络，再审批完整提案。Job Object 管理资源和子进程。项目代码按当前用户权限访问系统和网络。常规运行时通过环境配置关闭已知依赖下载，但该配置无法约束任意项目代码。参考 [Windows Job Object](https://learn.microsoft.com/en-us/windows/win32/procthread/job-objects)。 |
| 截图 | 用户主动触发捕获并审阅结果。裁剪及遮盖变更会让旧审阅失效。外发前再次显示目标 Provider、模型和图像。 |
| 桌面 | 已验证写操作为专用测试窗口的 UIA 语义操作。Notepad 仅候选 Microsoft.WindowsNotepad 包的单一空白、可写 UIA Document，在实际版本手动验收前保持 CONDITIONAL。禁止全局输入和坐标执行。 |

API Key 由当前 Windows 用户的 DPAPI 加密保存。普通审计事件记录动作类别、时间、哈希和错误码。工作区动作的准确差异、核验数据及命令输出可保存在本地产品数据库，恢复副本位于原文件旁，按本机 ACL 管理。用户在提交前应检查拟发送的代码、任务上下文和截图。项目代码可能在输出中包含任意数据，常见秘密字段遮盖不能替代对工作区和输出的审查。

文件删除、批量覆盖、第三方扩展代码执行、全局输入及静默提权处于关闭状态。环境安装当前提供官方来源和人工步骤。应用内固定安装执行等待验收。
