# Asimi 连接器、统一调度与深度进化设计
日期：2026-11-14。继续执行用户已明确批准的六能力路线，真实连接器验收限定公开 GitHub 只读，真实模型允许使用进程 DEEPSEEK_API_KEY。
## 目标与边界
保留已有文件、命令、桌面与学习闭环。新增可审阅的外部连接和操作、普通模式统一目标入口、基于证据的技能评价与记忆治理。密钥不进入日志、源码、报告或模型上下文。私人账户服务在没有账户时采用协议测试并明确未实测。
## 架构
连接器统一契约包含身份、服务地址、精确资源/工具范围、凭据引用及配置版本。显式保存连接表示授权该范围；每次操作另有完整不可变审批，消费后不自动重试。网络断开、停止或无法确认的写入为 UNKNOWN/RECOVERY_REQUIRED，重启不重放。HTTPS 禁止跨主机重定向，回环 HTTP 仅用于本地 MCP 和测试。
统一目标入口 SubmitAgentGoal，支持 chat/development/desktop/communication，默认 auto。保留领域特有安全边界；调度记录拥有原始目标、所选领域、子任务/请求 ID 和事实状态。自动路由仅用于可确定的公开仓库读取/明确项目请求；模糊桌面目标需观察控件，不凭自然语言产生任意输入。
Evolution 从真实任务与版本绑定的技能使用中计算成功、失败、耗时及请求数；失败经验只归纳可证实错误。技能改进是待审版本，个人组合只引用已审核固定版本，允许工具为受限并集，执行时重校验。记忆治理保留高价值/显式记忆，过期或冲突条目停止召回并支持审阅，不自动删除。
本地数据目录是个人账户边界，同一目录中的工作区仍隔离。不同系统用户的 DPAPI 与独立数据库必须保持隔离；不能把工作区隔离宣传为完整在线多租户。
## 用户界面
普通模式有连接与统一任务入口，仅需模型、必要权限和外部账户；公开 GitHub 可免密。明确展示连接资源范围、审批、结果确认、缺少账户与未知结果。中英文完整，沿用现有 Vue 组件。
## 验收
真实 DeepSeek 模型发现与模型任务，真实 GitHub 公开仓库读取，真实专用 Windows 窗口 UIA。至少一次目标->连接器事实->模型总结->经验->后续复用。开发修复技能闭环和桌面链路保留回归。禁止向第三方发送测试邮件/消息或产生仓库写入。报告逐项区分实测、协议测试与未完成。
