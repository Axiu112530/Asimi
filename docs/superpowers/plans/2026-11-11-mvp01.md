# DeskPilot AI MVP 0.1 Implementation Plan

> Execute continuously under the user's supplied full-product authorization. Use independent agents for disjoint implementation domains, then integrate and review. No automatic commits or branch changes.

**Goal:** Integrate the existing prototype into a usable Windows desktop assistant with workspace, developer, command and task workflows.

**Architecture:** Preserve existing adapters and approval/recovery chains. Add bounded workspace primitives, a fixed command engine and v5-backed task/action orchestration, with real Vue surfaces.

**Tech Stack:** Go 1.26.0; Wails v3.1.0; Vue 3.5.45; SQLite; Windows UIA/.NET Framework helpers.

**Spec:** ../specs/2026-11-11-mvp01-design.md and the user's supplied MVP brief.

## Global constraints

- Keep all uncommitted Phase 0–2D work; preserve v1–v4 migration SQL.
- No shell command binding, global input fallback, automatic elevation or unapproved external model requests.
- Every effect needs exact per-action approval, backend revalidation, durable intent and verification.
- Window-first shutdown and UNKNOWN_RESULT no-replay remain mandatory.
- No commit, push, branch switch, historical report overwrite or evidence deletion.

## Review focus

- Workspace target replacement or reparse points between proposal and execution must reject safely.
- Concurrent approval, stop and database failure must not duplicate an effect or report unsaved success.
- Project tests can execute arbitrary project code and network; disclose and gate actual network capability.
- Interrupted tasks must reread current facts and never replay consumed/unknown effects.
- Missing providers, unsupported Notepad editors and unavailable runtimes must show actionable real errors.

## Implementation sequence and ownership

- [ ] 1. Baseline preservation: capture branch/HEAD/status, dependencies, migration and historical evidence hashes in `docs/mvp01-evidence`.
- [ ] 2. `internal/developer`: bounded project scan/search/read, language and dependency detection, scoped file-change prepare/apply and independent verification. Security tests cover traversal, links, stale content and exact one-file changes.
- [ ] 3. `internal/command`: fixed program/argument registry, redacted environment diagnosis, bounded Job Object process execution, cancellation and results. Tests cover denied shell/paths/arguments, output/time limits and process trees.
- [ ] 4. `internal/app/mvp_*`: immutable v5 migration; workspace persistence and native selection callback; unified file/command proposal broker; task/step persistence and skills; pause/resume/stop/recovery. Tests cover consumption, hashes, expiry, stale targets, restart and transaction failures.
