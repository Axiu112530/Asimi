# Asimi local files and cleanup

[English](CLEANUP-INVENTORY.md) · [简体中文 archive](CLEANUP-INVENTORY.zh-CN.md)

| Content | Purpose | Handling |
| --- | --- | --- |
| Source, manifests and Windows resources | Application and reproducible build inputs | Version controlled |
| Scripts, fixtures and locale baselines | Reproducible checks | Version controlled under existing rules |
| Reviewed documentation and release summaries | User guidance and recorded results | Version controlled |
| .phase0-tools and .phase0-cache | Local toolchains and offline caches | Ignored, rebuild preparation required after removal |
| frontend/node_modules and frontend/dist | Installed dependencies and embedded bundle | Ignored, generated by install/build |
| .local-validation | Isolated test profiles and workspaces | Ignored |
| build/bin | Binaries, ZIP files and extracted test copies | Ignored |
| Raw acceptance logs and databases | Local diagnostics and private fixture state | Ignored |

Earlier cleanup removed ten regenerable output directories totaling 239,969,865 bytes, then 952 WebView2 cache directories totaling 994,866,012 bytes. Fifty-eight redundant test batches were moved to a local archive. Referenced upgrade samples and historical archives were retained. Detailed historical handling is recorded in the Chinese archive.

Close fixture processes before clearing their data. Preserve referenced samples when replaying earlier acceptance. Keep personal application profiles and backups private. The current default profile is %LOCALAPPDATA%\Asimi. [Privacy](../../PRIVACY.md) · [Contributing](../../CONTRIBUTING.md)
