# DeskPilot 0.2 安全审查

| 边界 | 处理 |
| --- | --- |
| 模型输入 | 用户选定工作区，有界扫描，敏感路径拒绝，源文件及测试输出遮盖后在客户端预览。发送前比较审阅哈希。 |
| 模型输出 | JSON 限深和限长，拒绝重复字段、未知步骤及一次多个副作用。只能使用已注册类型。 |
| 目标 | 任务绑定工作区目录身份，文件提案绑定完整的已审阅源文件、当前原始 SHA-256、父目录及目标身份。 |
| 审批 | 精确单动作，动作哈希覆盖任务、计划版本、步骤、策略、目标、参数和过期。单次消费与执行意图同事务。 |
| 文件 | 保留 TxF、恢复副本、独立重读。拒绝目录穿越、重解析点、符号和硬链接。 |
| 命令 | 固定程序与数组参数，预览目录及网络风险。Agent 只允许注册的可提议模板。Job Object 限制及取消进程树。 |
| 电脑 | 绑定用户选择的观察，既有 UIA 精确提案与审批、验证。真实 Notepad 和桌面视觉待用户手动验收。 |
| 恢复 | 模型请求预算发送前落库，重启不会自动发请求。执行意图未解决时要求核对状态。停止取消活动请求和未消费审批。 |
| 密钥 | BYOK 由 Windows DPAPI 处理。验收专用入口从进程环境读取 DeepSeek 密钥，使用固定官方端点，报告仅含结果元数据和计费数字。 |

常见秘密规则无法识别所有自定义凭据，发送前由用户核对预览。Job Object 是进程管理边界，项目测试和构建以用户权限运行。用户确认网络风险不代表网络隔离。0.2 不提供一般应用写入、全局 SendInput、坐标点击或自动安装。
