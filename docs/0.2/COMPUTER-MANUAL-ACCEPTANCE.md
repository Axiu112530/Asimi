# DeskPilot 0.2 电脑任务手动验收

真实桌面截图与 Microsoft 记事本写入等待用户在最终版应用内验收。合成截图、回环服务和专用 Windows 测试窗口的结果可以单独记录。

## 准备

1. 从解压后的便携目录打开 `DeskPilotAI.exe`，在「工作区」选择一个临时目录，再在「任务」创建一个易于识别的任务，例如 `DeskPilot 0.2 电脑手动验收`。记下任务名称和 ID。两项验收使用同一个任务。
2. 在「模型」配置你允许接收测试图像的 Provider，确认端点与模型的图像能力。打开一个只包含无害测试内容的窗口，例如显示 `DeskPilot 0.2 screenshot sample` 的空白测试页面。

## 实际截图

1. 打开「电脑」，点「分析截图」。选择显示器，圈选测试窗口内的区域，勾选截图确认并捕获。
2. 检查预览与屏幕内容一致。按需裁剪或遮挡，在「关联到任务」选择验收任务，输入关于可见内容的问题，打开上传审阅。
3. 核对审阅中的任务名称、API 主机、模型、预览、字节数和 SHA-256。点「发送给 AI」一次，等待「助手」显示分析。对照截图检查回答是否符合实际可见内容。
4. 回到「任务」，打开验收任务。在「电脑操作记录」中核对「截图分析」及其请求 ID。打开对应会话，核对分析来自刚才审阅的截图。分析请求完成状态表示 Provider 已返回，结果准确性由你对照预览确认。

## 空白 Microsoft 记事本

1. 自行打开 Microsoft 记事本，创建新的空白窗口或标签页，关闭记事本弹窗。在「电脑」列出目标窗口，选择这个记事本窗口并检查控件树。
2. 选择唯一空白、启用、可写且支持 `ValuePattern` 的编辑控件。如果界面判定不符合条件，记录窗口版本和原因，结束本项并标记为「当前配置不兼容」。
3. 在「关联到任务」选择同一验收任务。输入 `DeskPilot 0.2 Notepad sample 你好`，点「设置测试输入值」。在「审批中心」核对任务、窗口、控件、完整文本和到期时间，点「批准动作」一次。
4. 检查记事本的实际文本与样例完全相同，并核对「动作时间线」的结果为「已完成」且显示「已验证」。回到「任务」，在「电脑操作记录」核对同一动作 ID 和结果。用户可关闭并丢弃本次空白测试文档。
5. 若状态为结果未知或需要恢复确认，先查看目标的实际内容并记录现状。任何后续尝试都从新的空白窗口观察和独立审批开始。
