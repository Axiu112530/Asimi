# DeskPilot AI MVP 0.1 使用指南

启动应用后按向导选择语言。可以配置兼容 Provider、模型和 API Key，也可以继续离线。连接测试需要主动确认。视觉能力按模型显示，只有明确支持视觉的模型才可发送图片。设置中可切换语言和主题。

1. 在 **Assistant** 选择真实 AI 模式，再选择 Provider 和模型。输入消息后审阅发送确认。回答支持 Markdown、代码块、流式输出与取消。会话可在 History 中恢复，用量和价格在 Usage 查看。
2. 在 **Computer** 选择显示器并主动捕获。预览后可裁剪或遮盖敏感区域。确认传输目标及图像后才发送视觉分析。控制测试窗口的启动、输入、提交和重置都要逐条审批。
3. 在 **Workspaces** 使用原生目录选择器选择本地项目。在 **Developer** 分析目录、搜索代码、查看文件、依赖、符号和调用提示。可在分析前填入排除目录。想让模型解释文件时，先确认助手草稿只包含愿意发送的内容。
4. 在 **Developer** 输入工作区相对路径和完整替换文本，生成 Diff。核对目标、差异和内容，再批准此动作。现有文件的事务替换要求本地 NTFS 支持。失败或结果未知时，重新读取文件并核对保留的恢复副本。
5. 在 **Developer → Environment** 启动诊断。检查各运行时的版本、可执行位置和官方来源。在项目命令面板选择受支持的命令，检查目录、参数、网络和项目代码风险后单独批准。定向测试可填写相对目标。
6. 在 **Tasks** 选择工作区并输入目标。任务记录项目、搜索、环境步骤和总结。可预览任务上下文，再选择 Provider 请求分析。通过任务的下一步动作入口可以把独立文件或命令提案挂到任务。需要中止时使用任务取消或顶部 Stop All。

## Notepad 手动验收

先打开新的空白 Microsoft Notepad 窗口。到 **Computer** 刷新目标并检查该窗口。只有 UIA Inspector 明确显示单个符合条件的空白编辑器时才会出现文本提案。使用无害样例文字，核对目标和准确文本后批准一次。观察应用界面和时间线，确认文字出现并标记为独立核验成功。保存文档仍由用户操作。

若窗口有已有内容、多个编辑器或只有只读 TextPattern，保持观察模式。遇到 Recovery Required 或 Unknown Result 时先核对实际状态，再决定是否发起新动作。
