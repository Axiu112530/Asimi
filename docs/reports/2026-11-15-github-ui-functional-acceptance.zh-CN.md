# Asimi GitHub 端 UI 与功能验收报告

日期：2026-11-15。范围：GitHub 开源仓库 `Asimi`，基线提交 `01081b0` 加本轮工作区修改。环境：本机 Windows、Vue 3 / TypeScript / Vite、Go / Wails / WebView2。测试使用独立数据目录与生成的 Go 项目。

## 1. 验收结论

**结论：核心路径通过，自动学习保留明确条件，适合继续内测。**

Harness 的真实修复、逐项审批、测试验证、文件回读和重启恢复均已通过。Skills 的自动候选生成、审核后启用、版本文件落盘与后续任务实际复用分别取得了验证证据。本轮修复了授权勾选被刷新清除、任务跳转无法定位、学习结果不同步等实际问题。

需要保留的限制：两次真实模型加强验收中，首轮计划被严格解析器拒绝，任务重试后仍然完成修复和测试，但学习器按现有规则没有生成技能候选。不能把“任务完成”当作“必定产生技能”，也不能据少量成功样本宣称通用、稳定的自主学习。

## 2. 本轮修改与 UI 判断

| 项目 | 原有问题 | 本轮结果 |
| --- | --- | --- |
| 模型配置与授权 | 对话、项目任务需要的模型授权藏在折叠区，提交被禁用时缺少可见解释 | 按任务类型展开模型选项，显示缺少模型、授权或项目的说明；模型缺失时可直接进入配置 |
| 连接器授权 | 轮询返回新的连接对象，即使授权版本没变，也会清空勾选 | 改为分别监听动作 ID、摘要和连接版本；相同内容刷新保留勾选，版本或请求变化仍撤销授权 |
| 来源任务定位 | 首页、目标任务、学习记录进入工作流后没有准确定位 | 同步任务选择，突出对应任务，滚动到该任务并移入键盘焦点 |
| 学习结果说明 | 学习作业“完成”容易被理解为已经学出了可用技能 | 根据服务端数据区分待审核草稿、已审核并启用的技能、仅处理经验而暂无可用草稿 |
| 学习实时更新 | 后台已完成，页面可能一直显示处理中 | 后台提交完成或成功记录失败后通知；前端合并事件刷新，保留项目范围，丢弃过期响应并释放资源 |
| 普通模式入口 | 学习空状态缺少清晰的下一步 | 提供进入目标任务的入口，保留个人知识与项目知识的明确范围 |
| 国际化与视觉反馈 | 新说明和任务选中态不完整 | 补齐中英文资源；保持现有布局、配色与组件体系，增加克制的选中边框和焦点反馈 |

当前桌面布局适合任务型应用：普通模式保留常用入口，开发模式展开项目工具；宽屏显示文字导航，较窄视口使用图标导航及标题提示。主要操作、审批详情、来源任务与结果现在能连贯访问。本轮保持现有桌面视觉体系，新增说明均来自真实状态。

原生截图与尺寸检查覆盖首页、目标任务、连接器、设置、模型、用量、电脑、技能、记忆、学习、成长，以及普通模式主要页面。中英文、深浅主题均有实际截图。重点查看了首页、任务、工作流定位、学习结果、技能、记忆、连接器和深色视图。

### Skills 的实际工作方式

当前流程为：**完成任务 → 检查可验证证据 → 保存候选 → 用户审核 → 启用版本包 → 后续任务选择与使用 → 继续审批实际命令 → 验证结果。**

“自动创建技能”需要在记忆设置中开启；当前新配置默认关闭该选项。开启后也会遵守证据和失败记录的限制。学习作业完成仅代表处理结束，页面现在会明确显示产出情况。

SQLite 是状态来源。审核后的文件投影位于：

```text
<应用数据目录>/skills/<生成的包 ID>-v<版本>/SKILL.md
<应用数据目录>/skills/<生成的包 ID>-v<版本>/manifest.json
```

本轮真实任务在重启确认候选仍待审核后，另外通过正常后台服务审核了该候选；实际生成 `skills/53fbee57b9fdbea1c5c4dfccb1176d4f-v1/`。文件回读、版本 1、来源任务、命名空间、执行声明、校验摘要及正式导出均通过；这一步没有额外模型或网络调用。

当前已经证明的自动本地执行能力是：**已审核的 `go.test` 技能，针对最近经过独立验证的 Go 修改运行相应包测试**。执行仍需要当前版本、来源、依赖、工具许可和动作审批。其他已学习、手工或导入的技能主要提供工作指导与上下文；本次不能将其统称为任意语言、任意脚本的自动执行能力。

Harness 注册了 Go、Node、Java、.NET、pytest 和 unittest 等固定测试入口；本轮真实模型修复样本是 Go。Java 和 .NET SDK 兼容性检测未满足当前测试环境要求，相关用例跳过。

## 5. 本轮发现的失败及处理

1. **连接器勾选消失：已修复。** 单个 getter 每次返回新数组，刷新连接对象会触发清空。改为多来源原始值监听，并用组件及真实跨轮询检查复验。
2. **学习页长期处理中：已修复。** 后台缺少完成通知，前端缺少对应订阅。现在在事务提交和锁释放后通知，页面合并刷新；覆盖失败落库、空闲不通知、断线、切换范围和卸载。
3. **原生验收驱动的旧假设：已修复。** 等待控件可用再点击；显式选择项目范围；连接适配器识别当前表单的模型字段；真实开发 fixture 启用并写入重启断言依赖的学习状态。
4. **DeepSeek 首轮非法计划：保留项。** 两次加强复跑遇到 `AGENT_PLAN_INVALID`，重试修复成功后仍没有可信自动候选。严格拒绝多动作、提前完成、未知字段等规则保留。先前被拒的原始响应未保留，无法诚实判定其具体格式子原因；补充诊断捕获的是一个合法计划，回放及非法变体拒绝测试通过。
5. **公网读取间歇拒绝：记录保留。** 两次 GitHub 读取失败发生在模型摘要前，后续真实验证通过。没有用本地伪造仓库数据代替成功结果。

## 6. 性能、资源与发布边界

没有新增前端运行时依赖。最终主 JS 约 492.24 kB，gzip 约 163.21 kB；CSS 约 72.87 kB，gzip 约 14.59 kB。本地缓存已存在，本轮 Vite 构建约 0.16 秒，该时间不代表全新机器安装或冷启动性能。

学习事件使用 120ms 合并；后台空闲 350ms tick 不产生刷新事件。页面卸载会释放监听和计时器，断线及过期请求不能替换当前数据。`prefers-reduced-motion` 在真实 WebView 中验证生效。

最终原生开发测试主进程采样峰值约 49.8 MB，未包括全部 WebView 子进程。没有进行长时间稳定性、完整进程树峰值或帧率基准，报告不据此承诺长期性能。

本地验收运行程序：`build/bin/acceptance-20261115/Asimi.exe`。同目录的两个原生辅助程序及其配置文件需要保留。该目录属于本地验收产物，本轮没有生成新版本安装包或改动现有 GitHub Release。

## 8. 未完成与适用限制

- 自动学习对包含失败步骤的已恢复任务仍采用保守策略。可手工保存关联经验的指导技能；当前没有直接把此类任务提升为自动可执行技能的入口。
- 已验证的本地自动执行技能限于受控 Go 测试；跨语言真实修复、大型仓库、多文件连续改造不属于本轮样本证明的能力。
- GitLab、Microsoft Graph、Slack 和 MCP 的相关适配逻辑有本地测试覆盖，本轮真实外部服务验证为公有 GitHub；没有测试对真实第三方账户发送消息、邮件或写入资源。
- 桌面 Harness 本轮验证的是专用宿主与现有允许的控件操作，不能据此宣传任意软件、多应用自主操作均已完成。
- 本轮验证为 Windows。Cloud、Plus、其他操作系统和支付订阅没有纳入本次回归。
- 上述限制仍应反映在功能介绍和发布说明中。
