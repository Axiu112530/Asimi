## 用户手动验收

1. 在「模型」新增支持所选协议的服务商，填写 API Base URL、模型 ID 和已知能力。在应用内保存自己的 API Key。
2. 点击「测试连接」或在「模型实验室」发送一条文本，确认供应商、模型、响应和报告用量。开启流式后发送一条较长请求，再点击取消。
3. 在「助手」选择真实 AI 模式，继续多轮对话，重启后检查历史、模型标识和价格快照。
4. 选择有视觉能力的模型和一张测试图片，阅读发送提示后确认。检查回复是否描述了可独立核实的图片内容。
5. 记录实际服务商、模型、文本及视觉验收结果。密钥留在应用内。检查完成后可删除密钥与测试会话。

测试命令与隔离配置见 [测试策略](TEST-STRATEGY.md)。Phase 2C 等待验收决定。
