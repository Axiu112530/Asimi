# 从 DeskPilot 0.2 升级

1. 完全退出 0.2。在「设置 → 关于」记下数据目录。默认目录为 `%LOCALAPPDATA%\DeskPilotAI`。
2. 备份整个数据目录。备份应由同一 Windows 账户保护。DPAPI 凭据受用户账户和设备约束，迁往另一账户或设备后可能需要重新输入 Key。
3. 将 0.2.1 解压到新的程序目录。使用原 Windows 账户启动。自定义过数据目录时，以 `--data-dir "原数据目录"` 启动。应用需独占该配置，关闭旧进程后再升级。
4. 检查供应商、默认模型、主题、语言、历史、任务和审批。默认值仅为缺省项目补齐运行时配置。高级设置可恢复 AI 请求和 Agent 的默认上限。
5. 如需恢复，关闭新版本并以升级前备份替换数据目录，然后从旧程序目录启动。保留升级后数据目录供故障排查。

仅将数据目录复制到本地受控位置。故障报告请提供版本、错误代码及脱敏诊断。
