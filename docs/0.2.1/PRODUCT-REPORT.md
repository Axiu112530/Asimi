# DeskPilot Community 0.2.1 产品报告

## 使用流程

在 Windows x64 解压运行，选择界面语言。AI 连接页提供实际验证过的 DeepSeek 预设，也可跳过并离线使用。测试成功后使用 DPAPI 保存 API Key 并选定默认模型。准备页可以选择本地项目。应用会显示项目和运行时检测结果，以及支持范围内的只读 Git 状态。

从任务页提出目标。DeskPilot 会推荐少量相关源文件，用户可以改选。每轮外发前都会提供上下文预览。应用会对模型计划做结构校验，执行有界的只读步骤，并对文件修改和命令分别要求审批。文件审批绑定当前内容和身份，已有本地改动会出现在风险提示及完整 Diff 中。最终报告依据实际文件回读与测试结果。

## 交付和限制

| 范围 | 状态 | 说明 |
| --- | --- | --- |
| 首次向导、离线模式、默认配置和高级设置 | IMPLEMENTED | 默认值按缺省解析，可降低 Agent 和图片限制，恢复默认前要求确认。 |
| 项目识别与 Git | IMPLEMENTED | 检测常见项目和运行时。Git 直接读取受支持的本地仓库格式，提供已暂存、未暂存及未跟踪状态。 |
| 模型驱动的电脑建议 | IMPLEMENTED | 限专用测试窗口。观察、图片外发、建议审阅、逐动作审批和独立核验分别留痕。 |
| 真实桌面和空白 Notepad | PENDING | 需用户在最终包中主动完成。 |
| 正式开源发布 | PENDING | 项目所有者需先确定应用许可证。 |

实际执行结果及发布决定记录在 [验收报告](ACCEPTANCE-REPORT.md)。参见 [快速开始](START-HERE.md)、[升级指南](UPGRADE.md)、[安全审查](SECURITY-REVIEW.md) 和 [已知限制](KNOWN-LIMITATIONS.md)。
