# Community release preparation

The candidate is a Windows x64 portable ZIP with the app, two pinned helpers, the matching runtime configurations, documentation and a per-file SHA256 manifest. The build also records the archive hash and the executable hash from an independent extraction.

The application license remains an owner decision. Dependency notices identify and preserve third-party terms. They do not grant permission to redistribute DeskPilot. Public repository or Release creation is pending that decision and explicit authorization. See the acceptance report for the candidate decision and evidence.

The current decision is CONDITIONAL GO for a controlled candidate trial. Native functional acceptance passed 308 assertions, including a real DeepSeek connection and three-round Go repair. The final executable completed the two-hour loopback stability workload. User-initiated real desktop and blank Notepad acceptance, additional Windows versions, and the owner-selected application license remain release conditions. [Acceptance report](ACCEPTANCE-REPORT.md)
