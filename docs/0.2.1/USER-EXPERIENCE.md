# Community user experience

First launch presents Welcome, AI connection and Ready. Language selection is persisted from Welcome. The connection screen shows the recommended model, explains credential storage and the request sent by the test, and supports offline setup. Ready offers project selection. The Developer view updates when the selected workspace or exclusions change.

Home shows the default model or the offline entry. Settings groups startup, AI providers, appearance, language, privacy and advanced settings. AI Providers offers connection status and a collapsed editor for custom endpoints. Advanced settings expose actual limits and provenance. The interface has English and Simplified Chinese resources. See the release evidence for exercised paths and tested Windows versions.
