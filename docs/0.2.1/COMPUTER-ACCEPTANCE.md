# DeskPilot 0.2.1 电脑视觉和操作验收

使用最终便携包和独立测试 profile。电脑视觉需要已配置且明确支持图像输入的 Provider 模型。真实视觉 Provider 和 Microsoft 记事本均由用户主动验收。

## 视觉与模型操作建议

1. 在「任务」中准备一个测试任务。在「电脑」发起专用测试窗口的启动提案，审阅后批准。将专用窗口放在显示器上可见的位置，关闭或移开含敏感信息的窗口。
2. 刷新目标列表，检查专用窗口，选中 TestInput，并在动作区域选择测试任务。点击「请 AI 建议操作」。当前观察有效期为一分钟。超时后重新检查并发送新的请求。
3. 选择显示器或区域，勾选截图确认并截图。查看预览，可按需裁剪、遮挡或压缩。保留所选控件的可见区域。填写目标，例如「在选定的测试输入框填写 Hello DeskPilot」。
4. 检查 Provider、模型、主机、图片大小、费用提示、任务和所选控件，再确认发送。取消发送时应保留测试输入框的原状态。
5. 等待「电脑操作建议」返回状态。模型可以拒绝给出建议，无法使用的响应和过期观察应显示各自状态。可审阅时点击「审阅具体操作」，核对操作、目标和完整文本。此时测试输入框仍应保持原状态。
6. 单独批准一次。确认输入框内容、日志中的「已完成」与「已验证」，并在关联任务中检查真实观察时间、模型分析链接和动作证据。换选 SubmitButton 或 ResetButton 时重新检查并重新走审批流程。
7. 测试拒绝、过期和紧急停止。各场景均先创建新观察。拒绝或过期的审批、已消费的建议、已替换的观察和停止状态均不能触发新的桌面动作。
8. 打开分析会话，进行一次文字追问。追问走普通文字请求。由用户检查 Provider 的请求记录时，追问中应没有原始截图。

## Microsoft 记事本空白文档

状态为 **CONDITIONAL**，等待最终便携包的用户验收。模型建议入口仅对专用测试窗口开放。

1. 自行打开 Microsoft 记事本，创建新的空白窗口或标签页，关闭记事本弹窗。在「电脑」列出目标窗口，选择这个记事本窗口并检查控件树。
2. 选择唯一空白、启用、可写且支持 `ValuePattern` 的编辑控件。如果界面判定不符合条件，记录窗口版本和原因，结束本项并标记为「当前配置不兼容」。
3. 在「关联到任务」选择同一验收任务。输入 `DeskPilot 0.2.1 Notepad sample 你好`，点「设置测试输入值」。在「审批中心」核对任务、窗口、控件、完整文本和到期时间，点「批准动作」一次。
4. 检查记事本的实际文本与样例完全相同，并核对「动作时间线」的结果为「已完成」且显示「已验证」。回到「任务」，在「电脑操作记录」核对同一动作 ID 和结果。用户可关闭并丢弃本次空白测试文档。
5. 若状态为结果未知或需要恢复确认，先查看目标的实际内容并记录现状。任何后续尝试都从新的空白窗口观察和独立审批开始。
