# Asimi Community

This is the GitHub repository for Asimi Community. See the contribution guide for submitting changes and reporting issues. [Contributing](CONTRIBUTING.md)

Asimi is a local-first AI desktop assistant for developers, combining AI conversations, project understanding, code changes, controlled computer interaction, and secure local execution.

1. Extract the Windows x64 portable ZIP and open `Asimi.exe`. The setup guide starts in English and offers Simplified Chinese. [Installation guide](docs/release/INSTALLATION-GUIDE.md)
2. Connect DeepSeek using your own API key, configure a compatible endpoint, or start offline. Asimi protects saved keys with Windows DPAPI and stores preferences and history locally. [Privacy notice](PRIVACY.md)
3. Choose a local project and inspect its structure, Git status and runtimes. Confirm the context before sending it to your provider. Approve each file change or command separately, then review the verified result in the task timeline. [User guide](docs/release/USER-GUIDE.md)

The 0.2.1 release candidate is for controlled trials. Public release awaits the application license decision. [Known limitations](docs/release/KNOWN-LIMITATIONS.md) · [License decision](docs/release/LICENSE-DECISION.md)
